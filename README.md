**Maderas Los Puentes** es un proyecto real de digitalización empresarial que permite:

- Generar clientes automáticamente (leads)

## ⚙️ Instalación

### Clonar repositorio
```bash
git clone https://github.com/andreiarchdevops/maderas-los-puentes.git
cd maderas-los-puentes


Ejecutar local
python3 -m http.server 8000

Abrir en navegador:

http://localhost:8000
🚀 Despliegue
GitHub Pages
Activar en Settings → Pages
Seleccionar rama main
Servidor Debian + NGINX
sudo cp -r maderas-los-puentes /var/www/html/
sudo systemctl restart nginx

⚠️ Importante:
Asegurarse de que el servicio web esté activo después de reiniciar el servidor.
